# Architecture Decision Records

A decision listed in "Decisions that do not change without a new ADR" (product
plan §26) may only be reversed by adding an ADR here that supersedes the one
that set it. An ADR states what was decided, what it rules out, and what
evidence would force a revisit — not a summary of the discussion.
